# Lactomeda — Mission Control

A pixel-art space mission design game for NASA Space Apps 2026 (challenge: *Space Mission Design Game*).

Design a mission — objective, spacecraft, instruments, orbit, launcher — while juggling mass, power,
budget, data, comms and time. Then walk the corridors of the ship you built and keep it alive through
pop-up emergencies, alone or with up to 4 players.

- Setup: [docs/SETUP.md](docs/SETUP.md)
- Team rules for Claude Code: [CLAUDE.md](CLAUDE.md)
- Sources and NASA resources: [REFERENCES.md](REFERENCES.md)
